Cérebro local · Obsidian
O cofre organiza a personalidade, as informações aprovadas da loja e as perguntas frequentes. O Ollama consulta as notas revisadas a cada nova resposta; elas orientam o contexto, mas não treinam os pesos do modelo. 
Estilo, informações da loja e FAQ são lidos quando têm conteúdo. Para outras notas, use a pasta Conhecimento e marque atendimento: true. Preços, estoque e pedidos vêm do sistema. Conversas não são copiadas para o cofre. Backups .dbot novos incluem estas notas com criptografia; backups antigos continuam compatíveis. Nunca adicione dados de clientes.

Responsável e retenção
Ollama neste computador funciona sem envio a IA externa. Habilitar um provedor externo exige avaliar contratos, base legal e transferências internacionais. A limpeza preserva atendimentos pendentes; pode ser manual ou agendada na Proteção automática.

Exportações contêm dados pessoais: entregue apenas ao titular verificado e armazene com segurança. A remoção preserva itens e valores dos pedidos e não apaga cópias antigas ou dados dos provedores.

    Como publicar sua loja
    O endereço temporário é gratuito para testes e muda ao reiniciar o túnel. Links enviados com o endereço antigo deixam de abrir; o cliente precisa digitar 2 para receber um novo. Para o uso diário, configure um domínio fixo na Cloudflare.
    Assistente de domínio fixo
    Confira os passos para publicar seu domínio.
    1. Tenha uma conta Cloudflare e um domínio sob seu controle. Abrir guia oficial ↗
    2. Crie um túnel e uma aplicação publicada para o domínio de pedidos. Use o serviço HTTP com o destino local abaixo.
    3. Informe o domínio HTTPS, cole o token do conector e salve. O token é guardado protegido pela conta Windows.
    4. Inicie o túnel e gere um link de teste. Abra-o no celular usando dados móveis para validar o acesso externo.
    Destino que deve ser configurado no painel Cloudflare: http://127.0.0.1:5051 
    Ao ativar, a Cloudflare intermediará os acessos à página de pedidos, incluindo os dados informados pelo cliente. Confira seu aviso de privacidade. O token fica protegido pela conta Windows e não acompanha o backup portátil.
    
        
    Mantenha sua loja disponível
    O conector tenta se reconectar automaticamente quando a conexão cai. Mantenha o computador ligado, com internet e o aplicativo aberto ou na bandeja. Fechar completamente ou suspender o computador interrompe a página. O túnel não substitui hospedagem que funcione 24 horas com o computador desligado.
    Se você já usa ngrok ou outro serviço externo, pode continuar salvando seu endereço em Configurações com o túnel integrado desligado. Use domínio fixo para webhooks de serviços externos.
